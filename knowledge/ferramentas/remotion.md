# Remotion

## 📌 O que é
Framework para criar e renderizar vídeos programaticamente usando React, possibilitando geração de vídeos em escala via código.

- **🔗 URL Oficial:** [https://github.com/remotion-dev/remotion](https://github.com/remotion-dev/remotion)
- **📂 Categoria:** `video-conteudo`
- **⚙️ Tipo:** `open-source`

---

## 💡 Aplicação no Startuzeiro
Construção de micro-SaaS de vídeos personalizados ou criação automatizada de vídeos dinâmicos para redes sociais.
